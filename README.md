# Makita Corporation (6586 JP): Initiation of Coverage, Student Research Project

> Status: **Phase 0 (plan) complete.** Data, model and report are built in later phases.
> This is a student research project, not investment advice.

## The question
Is Makita, a Japanese cordless power-tool maker that reports under IFRS in JPY, fairly priced
after its post-COVID inventory reset? What do its fundamentals and a driver-based DCF imply for a
12-month target price?

## Deliverables (planned)
| # | Deliverable | Location |
|---|---|---|
| 1 | 3-statement + DCF + comps + sensitivity model, live formulas, Base/Bull/Bear switch | `model/` |
| 2 | 6-8 page initiation PDF (rating, 12-month TP, thesis) | `report/` |
| 3 | Reproducible data pipeline | `src/`, `data/` |
| 4 | Portfolio summary (120 words + 3 sentences) | `report/portfolio_summary.md` |

## Folder guide
```
data/raw/     untouched downloads (PDF filings, price/yield CSVs). Never edited by hand.
data/clean/   tidy CSVs produced by src/ scripts, one row per line item per fiscal year
model/        Excel model (generated by src/build_model.py)
report/       report source, charts, final PDF
notebooks/    exploratory analysis (historical ratios, charts)
src/          download, parse, clean, model-build and report-build scripts
SOURCES.md    every dataset: source URL, retrieval date, notes
```
