# Website: Makita (6586 JP) initiation

Static Vite site (vanilla JS, hand-written SVG charts, no runtime dependencies). Design spec: [DESIGN.md](DESIGN.md).

## Run locally
```bash
cd web
npm install
npm run dev
```

## Deploy to Vercel
1. Push this repository to GitHub.
2. In Vercel: **Add New... > Project**, import the repository.
3. Set **Root Directory** to `web`. Vercel detects Vite; build command `npm run build`, output `dist` (also set in `vercel.json`).
4. Deploy. No environment variables are needed.

CLI alternative, from inside `web/`:
```bash
npx vercel --prod
```

## Where the numbers come from
Everything in `public/data/` and `public/downloads/` is generated by the Python pipeline in the repository root
(`python src/pipeline.py --offline`). Do not edit those files by hand:

| File | Written by |
|---|---|
| `public/data/history.json` | `src/historical.py` |
| `public/data/valuation.json` | `src/valuation_charts.py` (from the recalculated Excel model) |
| `public/data/facts.json` | `src/export_web.py` (every figure quoted in the text, with its source) |
| `public/downloads/*.pdf, *.xlsx` | `src/export_web.py` (copies of `report/` and `model/`) |
